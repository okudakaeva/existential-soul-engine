# Existential Soul Engine 🛸👽💥

> **«Мы не знаем, существует ли любовь, но имеем на нее право!»**  
> — *Компилятор Квантовой Сингулярности*

`existential-soul-engine` — это интерактивный консольный арт-манифест и метапрограммный движок на **TypeScript**, исследующий фундаментальные законы человеческой души, скепсиса, догматизма и отношений через строгую призму предикатной логики, поп-культуры и стоической философии.

Проект визуализирует сотворение CLI-вселенной: от аннигиляции Абсолютного Добра и Зла в Большом Взрыве (`The Big Bang`) до принудительной синхронизации душ (`Force Overriding Protocol`) культовых персонажей (Фокса Малдера, Даны Скалли, Ричарда Касла, Кейт Беккет) и вычисления их экзистенциальной эффективности.

---

## 🎭 Архитектурная Драматургия (Бизнес-Логика)

Симуляция инкапсулирует базовые свойства человеческой личности в реактивные предикаты:
* **Стабилизация системы (`isStabilized`):** Бунтари и трикстеры изначально хаотичны, но стабилизируют свой продакшн, как только входят в контакт с партнерами-конформистами.
* **Скрытый Креатив (`embeddedIdeasGenerator`):** Сухие прагматики не генерируют идеи по умолчанию, но контакт с визионером-бунтарем активирует их скрытый творческий потенциал.
* **Право на Истину (`hasRightsToTruth`):** Математический предикат, доказывающий триумф свободного агностического разума.

## 🛠️ Инженерный Стек и Паттерны

Проект спроектирован по строгим канонам **SOLID** и промышленным стандартам веб-разработки:
* **Separation of Concerns (Разделение обязанностей):** 
  * `SoulInstance` — чистая модель данных и экзистенциальных теорем.
  * `Renderer` — низкоуровневый графический ANSI-движок.
  * `Scene` — оркестратор жизненного цикла, управляющий временем и побочными эффектами.
  * `Director` — ультимативный и единственный хозяин темпоральной сетки (Режиссер времени).
* **Реактивный асинхронный I/O конвейер (Итераторы и `yield`):** Методы вывода полностью избавлены от понятия времени и промисов. Они стали синхронными стейт-машинами, штампующими кадры анимации по требованию оркестратора времени.
* **Мета-генераторы (Генератор Генераторов):** Фаза Большого Взрыва управляется ленивым контейнером, который создает новые генераторы печатной машинки строк строго *on demand* — в момент завершения макро-промиса предыдущей строфы.
* **Context-Aware Markdown & Unicode Parser:** Кастомный  алгоритм разбора строки (`Renderer.highlight`), который налету сканирует ANSI-коды, находит маркеры `**токен**`, подсвечивает белым цветом и автоматически возвращает терминал к исходному контекстному цвету строки.
* * **Unicode & Surrogate Pairs Safety:** Посимвольный цикл печатной машинки защищен от разрывов сложных эмодзи (`👽`, `🛸`) с помощью динамического шага по кодовым точкам (`codePointAt`).

## 🎮 Интерактивное управление

Перед запуском саги движок производит полную очистку консоли (`TermControls.CLEAR_SCREEN`) и инициализирует квантовый клавиатурный перехватчик:
* **`[ПРОБЕЛ]`** — Мгновенная заморозка/возобновление симуляции в любой точке.
* **`[CTRL + C]`** — Экстренное прерывание программы.

## 🚀 Быстрый запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   cd existential-soul-engine
   ```
2. Установите зависимости (требуется Node.js):
   ```bash
   npm install
   ```
3. Запустите интерактивную сагу:
   ```bash
   npm start
   ```

## 🏛️ Квантовые Теоремы

Симуляция производит автоматический расчет двух фундаментальных теорем:
1. **Теорема Любви:** Доказывает, что даже при условии, что существование высших сил не подтверждено (`undefined`), право на незнание — неизменно, а значит, право на любовь компилируется в `true` для абсолютно каждого элемента социальной сети.
2. **Теорема Экзистенциальной Логики:** Математически уравнивает здоровый инженерный скепсис и живой мотор веры в Истину, реабилитируя сомневающийся разум от догматических штормов.
